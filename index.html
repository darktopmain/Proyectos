SOBRE MÍ

Ingeniería aplicada a problemas reales.

Mi especialidad es integrar hardware, software y datos para resolver necesidades reales de producción.

Soy ingeniero electrónico con experiencia en automatización industrial, desarrollo de software para manufactura, trazabilidad, bases de datos, microcontroladores e integración de equipos industriales.

He trabajado con sistemas que conectan computadoras con PLC, sensores, cámaras de visión, lectores de códigos, impresoras industriales y SQL Server para registrar, validar y monitorear procesos.

También desarrollo prototipos con Arduino, ESP32 y ESP8266, y utilizo impresión 3D para fabricar componentes funcionales para electrónica y automatización.
